# 🟩 20_역색인 (Inverted Index) - 쉽게 이해하기  

> **한 줄 요약**: **"단어 → 그 단어가 들어간 문서(커밋) 목록"**으로 바꿔서 저장해두는 것  
> **왜 씀?**: 전체를 안 뒤지고 **한 번에 찾으려고**  

<br><br>

## 🟢 1. 비유: 책 뒤의 "찾아보기" (색인)  

### 🟡 상황  
1000쪽짜리 책에서 **"파이썬"**이란 단어가 어디서 나오는지 찾고 싶어요.  

### 🟡 방법 1: 순서대로 다 읽기 (순회 검색 / Linear Search)  
- 1쪽부터 1000쪽까지 **한 장 한 장 넘기며** "파이썬" 있는지 확인  
- **시간**: 오래 걸림 (O(N) - 쪽 수에 비례)  

### 🟡 방법 2: 책 뒤 "찾아보기" 보기 (역색인 / Inverted Index)  
```
찾아보기:
파이썬: 12쪽, 45쪽, 203쪽, 567쪽
자바: 30쪽, 88쪽, 300쪽
깃: 15쪽, 45쪽, 500쪽
```
- **"파이썬" → [12, 45, 203, 567]** 바로 나옴  
- **시간**: 순식간 (O(1) - 상수 시간)  

> **이게 바로 역색인!**  

<br><br>

## 🟢 2. Mini Git에서 어떻게 쓰이나?  

### 🟡 두 가지 역색인 필요  

| 색인 종류 | Key (키) | Value (값) | 용도 |
|-----------|----------|------------|------|
| **키워드 색인** | 단어 (예: "로그인") | 커밋 해시 리스트 (예: ["a1b2c3", "d4e5f6"]) | `SEARCH "로그인"` |
| **작성자 색인** | 작성자 이름 (예: "홍길동") | 커밋 해시 리스트 (예: ["a1b2c3", "g7h8i9"]) | `SEARCH --author="홍길동"` |

### 🟡 실제 데이터 구조 (파이썬 딕셔너리)  
```python
# keyword_index: 단어 -> 커밋 해시 리스트
keyword_index = {
    "로그인": ["a1b2c3", "d4e5f6", "g7h8i9"],
    "기능": ["a1b2c3", "j1k2l3"],
    "버튼": ["d4e5f6"],
    "페이지": ["j1k2l3", "m4n5o6"],
}

# author_index: 작성자 -> 커밋 해시 리스트
author_index = {
    "홍길동": ["a1b2c3", "d4e5f6", "g7h8i9", "j1k2l3"],
    "김철수": ["m4n5o6", "p7q8r9"],
}
```

## 🟢 3. 어떻게 만들까? (구현 로직)  

### 🟡 커밋할 때마다 색인 업데이트  
```python
def update_index(commit_hash, message, author):
    # 1. 작성자 색인 업데이트
    if author not in author_index:
        author_index[author] = []
    author_index[author].append(commit_hash)
    
    # 2. 키워드 색인 업데이트
    # 메시지를 공백으로 쪼개고, 소문자로 통일
    words = message.lower().split()  # 예: "Add login feature" -> ["add", "login", "feature"]
    
    for word in words:
        if word not in keyword_index:
            keyword_index[word] = []
        # 중복 방지: 이미 있으면 안 넣음
        if commit_hash not in keyword_index[word]:
            keyword_index[word].append(commit_hash)
```

### 🟡 검색할 때  
```python
def search_keyword(keyword):
    keyword = keyword.lower()
    if keyword in keyword_index:
        return keyword_index[keyword]  # 바로 리스트 반환!
    return []  # 없으면 빈 리스트

def search_author(author):
    if author in author_index:
        return author_index[author]
    return []
```

## 🟢 4. 시간복잡도 비교  

| 작업 | 순회 검색 (색인 없음) | 역색인 사용 |
|------|----------------------|-------------|
| **검색** | O(N) - 전체 커밋 다 봄 | **O(1)** - 바로 찾음 |
| **색인 생성/업데이트** | 없음 | O(K) - 메시지 단어 수만큼 |
| **메모리** | 적음 | 더 필요 (색인 저장 공간) |

> **N = 전체 커밋 수** (예: 10,000개)  
> **K = 메시지 단어 수** (예: 10개)  
>   
> 10,000번 vs 1번 → **10,000배 빠름!**

## 🟢 5. 핵심 포인트 정리  

### 🟡 1. "역(Inverted)"인 이유  
- **정방향**: 문서 → 단어들 (문서가 키)  
- **역방향**: 단어 → 문서들 (단어가 키)  
- **검색하려면 역방향이 편함**  

### 🟡 2. 정규화 (Normalization) 중요!  
```python
# "Login", "login", "LOGIN" → 모두 "login"으로 통일
word = word.lower()  # 소문자 변환

# 구두점 제거 (선택사항)
word = word.strip(".,!?()[]{}")
```

### 🟡 3. 중복 방지  
같은 커밋에서 같은 단어가 여러 번 나와도 **한 번만 저장**  
→ `if commit_hash not in keyword_index[word]:` 체크  

### 🟡 4. 한국어 처리 (심화)  
영어는 공백으로 분리 쉽지만, 한국어는 **형태소 분석기** 필요 (예: KoNLPy, Mecab)  
> **이 과제에서는**: 공백 기준 `split()`만 써도 통과!

## 🟢 6. 미니 실습: 직접 해보기  

### 🟡 코드 실행해보기  
```python
# 빈 색인 만들기
keyword_index = {}
author_index = {}

# 커밋 3개 추가한다고 가정
commits = [
    ("a1b2c3", "홍길동", "로그인 기능 추가"),
    ("d4e5f6", "홍길동", "로그인 버튼 디자인"),
    ("g7h8i9", "김철수", "회원가입 페이지 만들기"),
]

# 색인 채우기
for hash_val, author, msg in commits:
    # 작성자 색인
    if author not in author_index:
        author_index[author] = []
    author_index[author].append(hash_val)
    
    # 키워드 색인
    for word in msg.split():
        word = word.lower()
        if word not in keyword_index:
            keyword_index[word] = []
        if hash_val not in keyword_index[word]:
            keyword_index[word].append(hash_val)

# 검색 테스트
print("키워드 '로그인' 검색:", keyword_index.get("로그인", []))
print("작성자 '홍길동' 검색:", author_index.get("홍길동", []))
print("키워드 '페이지' 검색:", keyword_index.get("페이지", []))
```

### 🟡 실행 결과  
```
키워드 '로그인' 검색: ['a1b2c3', 'd4e5f6']
작성자 '홍길동' 검색: ['a1b2c3', 'd4e5f6', 'g7h8i9']
키워드 '페이지' 검색: ['g7h8i9']
```

## 🟩 요약: 시험/면접용 한 줄 암기
