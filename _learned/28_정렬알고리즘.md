## 🟢 2. 정렬 알고리즘 성능 비교  

| 알고리즘 | 평균 시간 | 최악 시간 | 공간 | 안정 정렬? | 난이도 |
|----------|-----------|-----------|------|------------|--------|
| **병합 정렬** | O(n log n) | O(n log n) | O(n) | ✅ **예** | ⭐⭐ |
| **퀵 정렬** | O(n log n) | O(n²) | O(log n) | ❌ 아니오 | ⭐⭐ |
| **삽입 정렬** | O(n²) | O(n²) | O(1) | ✅ 예 | ⭐ |
| **버블 정렬** | O(n²) | O(n²) | O(1) | ✅ 예 | ⭐ |

### 🟡 추천: **병합 정렬** 또는 **퀵 정렬**  
- 둘 다 **O(n log n)**으로 빠름  
- **병합 정렬**: 안정 정렬(같은 값 순서 유지), 최악도 보장 → **추천!**  
- **퀵 정렬**: 실전 빠름, 제자리 정렬(메모리 절약)  

> **안정 정렬(Stable Sort)**: 같은 키 값을 가진 요소들의 **원래 순서가 유지**됨  
> 예: `(작성자, 시간)`으로 정렬 시, 작성자 같으면 시간 순서 유지

## 🟢 3. 병합 정렬 (Merge Sort) - 분할 정복  

### 🟡 아이디어: "쪼개서 정렬하고 합치기"  
```
[5, 2, 8, 1, 9, 3]
     ↓ 분할
[5, 2, 8]   [1, 9, 3]
  ↓          ↓
[5] [2, 8]   [1] [9, 3]
  ↓    ↓       ↓    ↓
[5] [2] [8]   [1] [9] [3]  ← 크기 1까지 쪼갬 (이미 정렬됨!)
     ↓ 합치기(병합)
   [2, 5, 8]     [1, 3, 9]
        ↓ 합치기
    [1, 2, 3, 5, 8, 9]  ← 완성!
```

### 🟡 핵심: **병합(Merge) 함수**  
이미 정렬된 두 리스트를 **하나로 합치기**  
```
left:  [2, 5, 8]      right: [1, 3, 9]
       ↑ i                   ↑ j

비교: 2 vs 1 → 1이 작음 → 결과에 1 추가, j++
비교: 2 vs 3 → 2가 작음 → 결과에 2 추가, i++
...
```

### 🟡 파이썬 구현  
```python
def merge_sort(arr, key=lambda x: x):
    """
    arr: 정렬할 리스트
    key: 비교 기준 함수 (기본: 자기 자신)
    return: 정렬된 새 리스트 (원본 안 바뀜)
    """
    # 기저 사례: 0개 또는 1개면 이미 정렬됨
    if len(arr) <= 1:
        return arr[:]
    
    # 1. 분할 (가운데로 쪼개기)
    mid = len(arr) // 2
    left = merge_sort(arr[:mid], key)
    right = merge_sort(arr[mid:], key)
    
    # 2. 병합 (정복)
    return merge(left, right, key)


def merge(left, right, key):
    """이미 정렬된 left, right를 합쳐서 정렬된 리스트 반환"""
    result = []
    i = j = 0
    
    # 둘 다 남아있는 동안: 작은 것부터 꺼내기
    while i < len(left) and j < len(right):
        if key(left[i]) <= key(right[j]):  # <= 로 안정 정렬 보장!
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    
    # 남은 것들 붙이기
    result.extend(left[i:])
    result.extend(right[j:])
    
    return result
```

## 🟢 4. 퀵 정렬 (Quick Sort) - 피벗 기준 분할  

### 🟡 아이디어: "기준(피벗) 잡고, 작으면 왼쪽, 크면 오른쪽"  
```
[5, 2, 8, 1, 9, 3]  피벗: 5 (보통 마지막이나 중간)
     ↓ 분할 (Partition)
[2, 1, 3]  5  [8, 9]  ← 피벗 기준 좌/우 분할
  ↓          ↓
[1, 2, 3]  5  [8, 9]  ← 재귀적으로 정렬
     ↓ 합치기
[1, 2, 3, 5, 8, 9]
```

### 🟡 파이썬 구현 (제자리 정렬 - in-place)  
```python
def quick_sort(arr, key=lambda x: x, low=0, high=None):
    """
    arr: 정렬할 리스트 (원본 수정됨!)
    key: 비교 기준 함수
    low, high: 정렬할 구간 인덱스
    """
    if high is None:
        high = len(arr) - 1
    
    if low < high:
        # 분할: 피벗 위치 확정
        pivot_idx = partition(arr, key, low, high)
        
        # 왼쪽/오른쪽 재귀 정렬
        quick_sort(arr, key, low, pivot_idx - 1)
        quick_sort(arr, key, pivot_idx + 1, high)
    
    return arr


def partition(arr, key, low, high):
    """피벗(마지막 원소) 기준으로 분할, 피벗 최종 위치 반환"""
    pivot = arr[high]
    pivot_key = key(pivot)
    i = low - 1  # "작은 것들" 영역의 끝 인덱스
    
    for j in range(low, high):
        if key(arr[j]) <= pivot_key:  # 피벗보다 작거나 같으면
            i += 1
            arr[i], arr[j] = arr[j], arr[i]  # 교환
    
    # 피벗을 올바른 위치로 이동
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1
```

### 🟡 퀵 정렬 변형: 랜덤 피벗 (최악 O(n²) 방지)  
```python
import random

def quick_sort_random(arr, key=lambda x: x, low=0, high=None):
    if high is None:
        high = len(arr) - 1
    
    if low < high:
        # 랜덤 피벗 선택 후 마지막과 교환
        rand_idx = random.randint(low, high)
        arr[rand_idx], arr[high] = arr[high], arr[rand_idx]
        
        pivot_idx = partition(arr, key, low, high)
        quick_sort_random(arr, key, low, pivot_idx - 1)
        quick_sort_random(arr, key, pivot_idx + 1, high)
    
    return arr
```

## 🟢 6. 시간복잡도 분석 (이해하기)  

### 🟡 병합 정렬: T(n) = 2T(n/2) + O(n)  
- **분할**: log₂ n 레벨  
- **각 레벨에서 병합**: 전체 n개 원소 처리 → O(n)  
- **총**: O(n log n) **항상 보장!**  

### 🟡 퀵 정렬: 피벗 운에 달림  
- **최선/평균**: 피벗이 중간 → T(n) = 2T(n/2) + O(n) = O(n log n)  
- **최악**: 피벗이 맨 끝(이미 정렬된 배열) → T(n) = T(n-1) + O(n) = O(n²)  
- **해결**: 랜덤 피벗 또는 중간값 피벗 사용

## 🟢 7. 삽입 정렬 (Insertion Sort) - 데이터 작을 때 유용  

> **작은 리스트(약 50개 이하)에서는 의외로 빠름!**  
> 병합/퀵 정렬의 **기저 사례**로 쓰기도 함 (하이브리드 정렬)  

```python
def insertion_sort(arr, key=lambda x: x):
    """제자리 정렬 (in-place), 안정 정렬"""
    for i in range(1, len(arr)):
        current = arr[i]
        current_key = key(current)
        j = i - 1
        
        # current보다 큰 것들을 오른쪽으로 밀기
        while j >= 0 and key(arr[j]) > current_key:
            arr[j + 1] = arr[j]
            j -= 1
        
        arr[j + 1] = current
    
    return arr
```

## 🟢 8. 실전 팁: 하이브리드 정렬 (Timsort 원리)  

```python
def hybrid_sort(arr, key=lambda x: x, threshold=32):
    """작으면 삽입 정렬, 크면 병합 정렬"""
    if len(arr) <= threshold:
        return insertion_sort(arr[:], key)  # 복사본 정렬
    return merge_sort(arr, key)
```
> 파이썬 내장 `sorted()`가 쓰는 **Timsort**도 이 원리!

## 🟢 10. 핵심 포인트 정리  

### 🟡 병합 정렬 쓸 때  
- ✅ 안정 정렬 필요할 때 (같은 키면 원래 순서 유지)  
- ✅ 최악 시간 보장 필요할 때  
- ✅ 링크드 리스트 정렬할 때 (메모리 효율적)  

### 🟡 퀵 정렬 쓸 때  
- ✅ 메모리 아껴야 할 때 (제자리 정렬)  
- ✅ 평균 성능 중요할 때 (캐시 친화적)  
- ⚠️ 최악 O(n²) 주의 → 랜덤 피벗 필수!  

### 🟡 Mini Git에서는  
- 커밋 수 보통 적음 → **병합 정렬 추천** (구현 쉽고 안정적)  
- `key` 인자로 비교 기준 유연하게 변경 가능
